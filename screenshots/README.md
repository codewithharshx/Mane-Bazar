# Mane Bazar — Application Screenshots & Asset Guidelines

This directory houses verified visual previews and interface screenshots of the **Mane Bazar** grocery e-commerce platform.

---

## Required Screenshots

To maintain a consistent, high-fidelity presentation on GitHub and in documentation, please save screenshots matching these file names:

| File Name | Interface View | Description | Suggested Resolution |
|-----------|----------------|-------------|----------------------|
| `homepage.png` | Storefront Homepage | Hero slider, top grocery categories, trust badges, and promotional offer strip. | `1920 × 1080` or `1280 × 720` |
| `products.png` | Product Catalog | Search results, category sidebar, price range filter, and product cards with stock badges. | `1920 × 1080` or `1280 × 720` |
| `cart.png` | Shopping Cart | Slide-over cart drawer / cart page showing item quantities, delivery fee calculation, and coupons. | `1920 × 1080` or `1280 × 720` |
| `checkout.png` | Checkout Flow | Customer address selection, order summary review, and payment option radio buttons (COD vs Online). | `1920 × 1080` or `1280 × 720` |
| `admin-dashboard.png` | Admin Dashboard | Real-time analytics, revenue area charts, order status distribution, and low inventory alerts. | `1920 × 1080` or `1280 × 720` |
| `mobile-view.png` | Mobile Experience | Mobile view showing responsive navigation, hamburger menu, and compact product cards. | `390 × 844` (iPhone / Android) |

---

## Guidelines for Adding Screenshots

1. **Format:** Use `.png` or `.webp` for clean typography and UI borders.
2. **Compression:** Optimize images with tools like [TinyPNG](https://tinypng.com/) to keep files under 1 MB each.
3. **Sensitive Information:** Blur any personal phone numbers, test credit card details, or private API keys before capturing.
4. **Theme:** Capture screenshots with clean browser window framing or frameless crops.
